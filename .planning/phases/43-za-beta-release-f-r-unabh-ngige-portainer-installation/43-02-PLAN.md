<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Portainer variables to Compose interpolation | Operator-provided secrets and host paths become runtime configuration. |
| ZA container to host storage | Read-only source data and writable application state cross the container boundary. |
| ZA container to MariaDB and Valkey | The application connects to persistent stateful services. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-04 | Information disclosure | tracked release env template | mitigate | Keep the template value-free and require Portainer variables for all secrets. |
| T-43-05 | Tampering | library bind mount | mitigate | Mount the operator library at `/romm/library:ro`; keep assets/config/resources separately writable. |
| T-43-06 | Denial of service | service startup | mitigate | Health-check MariaDB and Valkey, then gate ZA startup on both and pass external Redis configuration. |
| T-43-07 | Elevation of privilege | runtime host access | mitigate | Do not mount `/var/run/docker.sock`; fail required path/secret interpolation before startup. |
| T-43-SC | Tampering | container image dependencies | accept | The stack consumes documented OCI and database/cache images; no package-manager install is introduced in this phase. |
</threat_model>
