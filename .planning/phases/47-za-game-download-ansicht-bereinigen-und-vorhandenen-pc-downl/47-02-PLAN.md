<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| browser to manifest create API | Untrusted selection input requests a user-scoped manifest. |
| API to persisted inventory | A server-issued capability selects previously verified rows. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-47-04 | Elevation of privilege | whole-folder selection | mitigate | Verify ROM visibility, ownership, neutral kind, and persisted membership under locks. |
| T-47-05 | Information disclosure | capability serializer | mitigate | Emit counts and opaque selectors only, never a storage path or raw member inventory. |
| T-47-06 | Tampering | manifest selection | mitigate | Reuse immutable evidence capture and existing member delivery revalidation. |
| T-47-07 | Denial of service | large folder manifest | mitigate | Resolve server-side bounded persisted rows; retain scan limits and queue limits, not client fan-out. |
</threat_model>
