# Plan 50-03 Summary

Ready neutral FOLDER inventories are projected into the existing selection
dialog. The existing checkbox tree preselects members, supports deselection and
reselection, reports selected bytes from selected members, and sends the chosen
opaque IDs through the existing manifest and queue path. Preparable inventories
perform authorized preparation, refresh the existing detail data, and reopen
the same dialog before any manifest or transfer is started.
