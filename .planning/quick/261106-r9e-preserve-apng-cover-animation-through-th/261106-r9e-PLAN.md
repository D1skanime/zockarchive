# Preserve animated PNG covers through metadata selection

The metadata dialog persists selected covers through the filesystem resource
downloader. Preserve a PNG source when Pillow reports that it is animated,
while retaining the existing raw GIF/WebP behavior and image validation.
Manual owned-media uploads already validate and persist original bytes without
conversion. No tests are added during active UAT.
