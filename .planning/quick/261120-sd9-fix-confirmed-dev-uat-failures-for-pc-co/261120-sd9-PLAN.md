# Plan

## Scope

Resolve the three confirmed Dev-UAT regressions without changing production or NAS
data: selected PC subfolder retirement during a later quick scan, the Soundtrack
panel setup-time crash, and manual IGDB media refresh/publishing for screenshots
and artwork. Investigate the PS3 publication-date rendering while tracing the
manual metadata payload.

## Implementation

1. Trace the selected-child checkpoint and Windows inventory reuse path. Ensure a
   selected child reaches the collection finalization fence even when quick
   inventory reuses it, and that the retired parent cannot re-enter the catalog.
2. Move SoundtrackPanel playlist setup so no computed or watcher reads the local
   playlist before it is initialized. Preserve the existing MP3 media, playback,
   and download contracts.
3. Trace the manual IGDB match through owned-media publication and refresh.
   Repair the shared provider-media hand-off only where the persisted image data
   is lost or excluded, preserving user removals and provider suppressions.
   Correct the publication-date display only if the same normalized metadata
   trace proves it is wrong.
4. Update the relevant architecture documentation for any shared scan or media
   pipeline contract changed. Run static type/lint/build checks. The automatic
   Dev handoff makes the committed state available for the human UAT steps.
