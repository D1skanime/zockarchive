# Preserve scan-media recovery directory continuity

## Scope

Repair the full-shard regression where a receipt disappearing during bounded
recovery traversal causes its directory cursor to skip later relevant receipts.

## Tasks

1. Reproduce the failing continuity case through the same MariaDB CI shard and
   trace cursor advancement across a disappearing child and terminal priority.
2. Correct the traversal or recovery boundary while preserving UUID, manifest,
   ownership, fencing, and bounded-work invariants.
3. Add direct regression coverage, then run the full affected shard together
   with the cursor and crash-publication modules.

## Acceptance criteria

- A disappearing child cannot make later receipts in its directory unreachable.
- Terminal receipt priority remains intact.
- The affected CI shard and direct media-recovery contracts pass.
