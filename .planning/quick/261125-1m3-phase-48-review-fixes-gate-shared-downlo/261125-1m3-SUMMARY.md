# Quick Task 261125-1m3 Summary

Large PC single-file games now enter the shared downloader only through the
same persisted, complete neutral manifest evidence used by every folder source.

## Changes

- Full authorized PC scans publish a neutral single-file `FOLDER` component for
  qualifying simple sources while retaining all existing PC components.
- The shared download capability verifies one current `single-file-download`
  component, its one hashed member, and the matching recorded source size before
  exposing the 4 GB inclusive shared-download option.
- Missing, stale, incomplete, or mismatched neutral evidence leaves the
  existing ordinary download path intact and cannot trigger an on-demand scan,
  hash, or inventory rebuild from a response or manifest request.
- Updated the backend architecture document with the PC scan publication
  boundary and the read-only response and manifest contract.
